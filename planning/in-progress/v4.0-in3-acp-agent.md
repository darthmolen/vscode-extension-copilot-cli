## 3. Facts that cost real time — do not re-derive

1. **Never pass a method name as a string literal — use `acp.methods`.** `notify()` has an
   escape-hatch overload: a typo'd string **compiles clean** under `tsc --strict`. A typo on the
   constant is `TS2551`.
2. **`initialize` is not guaranteed to run.** `buildSession().start()` issues `session/new` alone.
   Handlers must work uninitialised. Security-adjacent: `clientCapabilities` gates permission
   forwarding, and branching on an unset capability **silently auto-approves** — the failure class
   cli#1607 is filed about. Default deny; let `initialize` *upgrade*.
3. **`session/cancel` is NOT free.** The prompt handler receives a `signal`, but **verified: a
   cancel notification does not abort it.** With no `onNotification` handler the cancel is silently
   dropped and the turn returns `end_turn`. Model it fire-and-forget — a notification has no reply,
   so throwing becomes an unhandled rejection rather than a client-visible error.
4. **The handler context is `{ params, requestId, signal, client }`** — not `context`.
5. **The client drives:** `clientApp.connect(agentApp)`.
6. **ESM/CJS is settled.** The SDK is ESM; we compile to CJS; `module: Node16` preserves
   `await import()`. The agent is its own process and never enters the extension bundle.
7. **ACP multiplexes** — every request carries `sessionId`.
8. **The SDK fills schema defaults before handlers run** (verified for omitted, `{}` and partial),
   which is why `upgradeCapabilities` is a plain assignment. Two tests pin that as an *SDK contract*
   and say so.

### Process lessons

**Read the source, not the `.d.ts`.** Three consecutive wrong API guesses came from type
declarations; what worked was dumping the live object:

```js
const keys = o => [...new Set([...Object.keys(o), ...Object.getOwnPropertyNames(Object.getPrototypeOf(o) || {})])];
```

**Mutation-test every claim.** It repeatedly found tests passing for the wrong reason — a capability
merge that was doing nothing, a regression test that did not discriminate, an assertion that passed
while the method under test was unimplemented. If a test cannot be made to fail, it is not yet a test.

**Check claims before repeating them.** Two assertions in this work turned out false on inspection —
"re-entering plan mode strands a session" (it guards) and "the release skill's version parser is
broken" (it is not). Both were nearly written into durable docs.

## 4. Next: permissions (scope item 4)

The manager hardcodes `onPermissionRequest: approveAll`. An ACP agent should forward to
**`session/request_permission`** instead.

**This is where fact 2 pays off.** Forwarding must be conditional on client capability, and
branching on an unset capability does not crash — it silently auto-approves. `CopilotAcpAgent`
already defaults deny and upgrades on `initialize`; consume `agent.clientCapabilities` rather than
re-reading params.

Suggested cycles, all testable in-process against the SDK's own client:

1. With a capable client, a permission request reaches `session/request_permission` and the
   client's answer is honoured.
2. With an **incapable** client (or no `initialize`), it does **not** silently approve — decide and
   test the fallback deliberately.
3. The reply shape round-trips: the double-nested `{ outcome: { outcome, optionId } }` documented in
   `tests/harness/acp-spike.mjs`.
4. `--yolo` does **not** suppress `onPermissionRequest` (spike finding), so a handler is always
   required.

Then: **remove `sdkSessionManager.ts`'s static fallback to `createVSCodeHostBridge` and split
`vscodeHostBridge.ts` out** — [memo](../backlog/hostbridge-split-and-fallback-seam.md). The
decoupling is true but not enforced by the module graph.

## 7. Repo rules that bite here

- **The suite is flaky.** A single red run proves nothing; **a single green run proves nothing
  either.** Re-run a failing file alone — and **not in the same breath as a full suite**, which can
  itself produce a false failure.
- **Squash-merge breaks ancestry checks.** `git merge-base --is-ancestor` false-negatives on
  anything squash-merged. Verify by **content** (`git diff --stat origin/main <sha>`).
- **`gh pr edit` is broken here** — it queries deprecated `projectCards` and **silently aborts**.
  Use `gh api -X PATCH repos/.../pulls/N -F body=@file`.
- **Never `git add -A`** — the sibling lane's untracked files land in your commit.
- **Commit messages with backticks need `-F file`**, not `-m`; bash expands them and silently blanks
  the text.
